# Синтетический каталог

[`testdata/mock_catalog.json`](../testdata/mock_catalog.json) — исключительно mock/demo data. Это не выгрузка ekt.kz, не источник текущих цены, остатков или доступности и не интеграционный контракт.

Набор содержит доступный товар на нескольких складах, товар с нулевым остатком, позиции с сертификатом, без сертификата и с неизвестными сертификатами (`null`), похожие кабели для будущего поиска аналогов, а также заведомо отсутствующий артикул `DEMO-UNKNOWN-404`.

Семантика полей модели:

- `null` означает `unknown/not provided` и не заменяется вымышленным значением;
- `[]` в `certificates` означает, что источник явно не сообщил ни одного сертификата;
- `cached_*` — снимок для разработки и будущей синхронизации, а не текущие данные;
- `source_fields` сохраняет дополнительные нормализованные поля источника без интерпретации.

`MockCatalogAdapter` загружает этот файл страницами в локальный индекс. Реальная загрузка уже имеет extension point `EktCatalogAdapter`, но может быть включена только после получения документированного JSON-контракта EKT и реализации `EktResponseMapper`.

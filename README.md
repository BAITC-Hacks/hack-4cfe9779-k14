# ИИ-ассистент для ekt.kz

Проект по кейсу HackAlem AI: чат на ekt.kz, который помогает посетителю найти электротехнические товары и оформить корзину.

Ветка `codex/ai-consultant` объединяет витрину React, FastAPI из `dev2` (`ee916bc`) и ИИ-консультанта на Responses API. При настроенном доступе EKT товары, цены, изображения и остатки приходят из API EKT; реальная корзина EKT пока не подключена.

[Отдельный CLI-консультант и общий ИИ-модуль](docs/consultant.md) также доступны: `uv run --frozen ekt-consultant` после `uv sync --locked`. CLI использует собственный демокаталог или JSON-снимок.

Для совместного запуска создайте `.env` из `.env.example` (не перезаписывайте существующий файл), задайте `POSTGRES_PASSWORD`, `OPENAI_API_KEY`, `EKT_API_USERNAME` и `EKT_API_PASSWORD`. Выполните `docker compose up -d --build`. Витрина: <http://127.0.0.1:8080>; API: <http://127.0.0.1:8000/docs>. Без EKT credentials каталог недоступен; backend не подменяет его синтетическими товарами.

Загрузка: до пяти PDF/DOCX/XLSX/JPEG/PNG по 10 МБ. Текст и таблицы извлекаются локально, изображения обрабатывает Tesseract; содержимое вложений не отправляется внешней модели. Поиск работает по загруженной части каталога (первые пять страниц при старте плюс просмотренные страницы).

Ассистент добавляет товар в корзину только после явного подтверждения клиента. Сервер проверяет количество и остаток непосредственно перед добавлением.

Исходные материалы: «HackAlem AI_ ИИ-ассистент для чата на сайте ekt.kz.pdf» и «ИИ-ассистент для чата на сайте ekt.kz ДАННЫЕ.docx.pdf». Учётные данные API не должны храниться в репозитории.

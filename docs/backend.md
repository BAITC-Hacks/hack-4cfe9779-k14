# FastAPI из dev2

Источник: `origin/dev2`, коммит `711e32347de793ec468a62a808828057113494d7`. В удалённом репозитории ветки `develop2` не было. Файлы бэкенда перенесены в текущую рабочую ветку без замены незакоммиченного CLI-консультанта, его pyproject и существующего web. Это импорт файлов, а не merge истории Git. Из исходной ветки сохранён каталог `widget` как прежний минимальный клиент; Compose запускает полноценный `web`.

Стек: Python 3.12, FastAPI, Pydantic v2, SQLAlchemy async, PostgreSQL 16, Alembic. Точка входа `app.main:app`. Слои: `api/routes` → `services` → `repositories`/`integrations`. Миграции в `alembic/versions`; синтетический каталог в `testdata/mock_catalog.json`.

Запуск и таблица подключённых API: [web/README.md](../web/README.md). `GET /health` проверяет базу; Swagger находится на `/docs`. Добавлен `GET /api/catalog/products` для начальной выдачи витрины. Поиск сохраняет прежнюю семантику пустого запроса. CORS разрешает `Idempotency-Key` для прямого подключения frontend к backend.

Настройки читаются из переменных окружения и игнорируемого `.env`. `.env.example` не содержит реальных секретов. В Docker DB доступна приложению по `db:5432`, с хоста — по `127.0.0.1:55432`. В контейнере API DATABASE_URL собирается из POSTGRES_*; для запуска Python на хосте укажите согласованный DATABASE_URL отдельно.

LLM подключается только серверными `LLM_API_URL`, `LLM_API_KEY`, `LLM_MODEL`. По умолчанию они пустые: маршрутизатор отвечает на явные вопросы о SKU, характеристиках, цене, остатках и условиях; свободный запрос может получить просьбу уточнения. Отдельный CLI-консультант из `src/` к FastAPI не подключался.

`CATALOG_ADAPTER_MODE=mock` читает синтетический каталог. Режим `ekt` пока возвращает недоступный адаптер: mapper реального JSON EKT в этой ветке не реализован. Basic Auth client существует, но одних credentials для включения источника недостаточно. `OfferService` повторно проверяет цену/остатки и применяет идемпотентность; реальный provider товара и `CartGateway` в маршруте остаются заглушками. Адрес корзины EKT не придумывается.

Дополнительные документы: [каталог](catalog.md), [чат](chat-flow.md), [вложения](chat-attachments.md), [подтверждение](offer-confirmation-flow.md), [EKT](ekt-integration.md). Разработка использует UUID сессии как идентификатор доступа; перед размещением на сайте нужна аутентифицированная привязка сессии и защита административных endpoints каталога. Текущее окружение запускается локально.

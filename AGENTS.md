# Правила работы агентов в проекте

## Локальные навыки

В репозитории сохранены два сторонних навыка. Перед применением прочитайте соответствующий `SKILL.md` целиком:

- [`ponytail`](skills/ponytail/SKILL.md) — применять при написании, исправлении, ревью и проектировании кода, а также при выборе зависимостей. Сначала изучить затрагиваемый код, затем выбрать самое простое решение, которое выполняет задачу. Не сокращать проверку входных данных, обработку ошибок, безопасность и доступность интерфейса. Режим по умолчанию — `full`; явный выбор пользователя имеет приоритет.
- [`i-have-adhd`](skills/i-have-adhd/SKILL.md) — применять по умолчанию к ответам и сообщениям о ходе работы в этом проекте: начинать с результата или следующего действия, давать короткие нумерованные шаги и выделять завершённую работу. Это проектное указание включает навык, хотя в его метаданных стоит `disable-model-invocation: true`. Если пользователь просит подробное объяснение, дать его полностью, сохранив ясную структуру. Пользователь может отключить режим явной просьбой.

Инструкции пользователя и правила среды имеют приоритет над локальными навыками. Навыки задают способ работы и подачи результата; они не меняют требования кейса.

## Контекст проекта

- Источники требований: два PDF кейса HackAlem AI, указанные в [`README.md`](README.md).
- Доступ из приложения с данными относится к API каталога, а не к админке сайта или корзине. Секреты не помещать в репозиторий, браузерный код и логи.
- Добавление товара в корзину возможно только после явного подтверждения клиента и повторной проверки количества и остатков на сервере.
- При отсутствии доступа к ekt.kz демонстрационная витрина и корзина должны быть явно обозначены как прототип; не выдавать их за действующий сайт или его корзину.

## Подключённый бэкенд

- FastAPI импортирован из `origin/dev2` (`711e323`); контракт и запуск — в `docs/backend.md` и `web/README.md`.
- Маршруты в `app/api/routes`, логика в `app/services`, SQLAlchemy-запросы в `app/repositories`. Изменения схемы — через Alembic.
- `CatalogService` — единая точка доступа к каталогу. `cached_*` из поискового индекса не выдавать за свежие цену и остатки; витрина использует `/fresh`.
- Корзину изменяет только `OfferService` после подтверждения конкретного offer_id с `Idempotency-Key`. Заглушки реального EKT и корзины сохранены до получения контрактов партнёра.
- Серверные ошибки имеют форму `{code, message}`. Запросы, файлы и секреты не логировать. Вложения привязаны к сессии.
- Проверки интеграции: `.venv/bin/python -m pytest -q`, `npm test --prefix web`, `npm run build --prefix web`.

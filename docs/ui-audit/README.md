# Сверка интерфейса с nursultan.ekt.kz

Обновлено 23 сентября 2026 года после сравнения с 17 скриншотами пользователя.

## Исправление прежней проверки

Предыдущие файлы `original-*-phone.png` и `local-*-phone.png` оставлены как история. Они **не подтверждают соответствие настоящему мобильному сайту**: тогда проверялся уменьшенный настольный шаблон. Оригинал отдаёт отдельный шаблон `ekt_mobile` для мобильного User-Agent. В текущей работе использованы его публичные HTML/CSS, каталог `/home/talgat/downloads/new reference` и скриншоты пользователя. При различиях между CSS и скриншотами приоритет имеют скриншоты.

## Что изменено

- Настольная версия: оригинальный SVG логотип, размеры шапки и баннеров, обычная прокрутка шапки, маленькие иконки в сетке 4×3, счётчик боковых баннеров.
- Телефон: одна закреплённая синяя шапка, поиск с камерой, телефоны и меню; нижняя панель из пяти пунктов; контурные SVG в четырёх колонках.
- Перенесены 12 основных баннеров, 12 боковых, по 10 новинок и спецпредложений, 20 карточек новостей. Видео и изображения локальные. Для видео извлечены заставки, чтобы до начала воспроизведения не появлялось пустое место.
- Восстановлены полный текст о компании, преимущества 2×2, карусель «Узнать больше», белый мобильный футер с подпиской и платёжными значками.
- На телефоне кнопка ассистента компактная и находится над нижней навигацией. Окно чата занимает экран. Демонстрационное назначение обозначено в названии страницы, футере и чате.
- Общий поиск теперь сбрасывает прежний фильтр категории.

## Проверки

- `npm run build`: успешно (TypeScript и Vite).
- `git diff --check`: без ошибок.
- В браузере проверены главный экран и его секции при ширине 400 px и настольный экран около 1750 px. Дополнительно проверены узкий экран 320 px и широкий телефон около 440 px: горизонтального переполнения страницы не обнаружено.
- На главной нет завершивших загрузку изображений с ошибкой. Проверено воспроизведение основного MP4 и наличие локального poster.
- Проверены переход к каталогу из нижнего меню, состояние пустой корзины, открытие/закрытие чата и размещение поля ввода внутри экрана.
- Субагент отдельно проверил исходные параметры оригинала и новые снимки. Замечания о пустом видеобаннере и сохранении фильтра при поиске исправлены.

## Пределы проверки

Это визуальная сверка в браузере, а не автоматическое доказательство совпадения каждого пикселя. Кадр видео, положение карусели, масштаб браузера и системный рендеринг шрифтов могут отличаться. Физический телефон не использовался. Чат, демонстрационные товары и локальная корзина — функции прототипа; подписка не отправляет данные на сервер, сервисные ссылки ведут на официальный сайт. Подключение к API партнёра этой задачей не проверялось.

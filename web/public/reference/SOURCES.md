# Источники оформления

Материалы для демонстрационной витрины взяты из предоставленной пользователем папки `/home/talgat/downloads/new reference` и публичных шаблонов https://nursultan.ekt.kz/ (23 сентября 2026).

- `logo.svg` — исходный встроенный SVG настольной шапки.
- `mobile/category-*.svg` — исходные встроенные SVG категорий мобильного шаблона `ekt_mobile`; цвет установлен в #2c7294, атрибут viewBox нормализован для отдельных SVG файлов.
- `mobile/icon_*.svg`, `mobile/kaspi_red.png` — изображения из `/local/templates/ekt_mobile/images/`.
- `cart.svg`, `catalog.svg` — те же иконки с цветами настольной шапки.
- Видео MP4 и рекламные изображения — из предоставленного референса. JPEG с тем же именем, что у MP4, — кадры на четвёртой секунде для заставок.
- `mobile/pt-sans-*.ttf` — PT Sans из Google Fonts. Лицензия находится в `mobile/OFL-PT-Sans.txt`.
- Порядок карточек и адреса публикаций сохранены в `web/src/homeContent.json`.

Код оригинального сервера, аналитика и формы отправки данных не переносились. Витрина является демонстрацией проекта с ИИ-ассистентом.

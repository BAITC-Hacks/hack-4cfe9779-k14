# Витрина EKT + FastAPI

Демонстрационная копия интерфейса EKT подключена к Python-бэкенду из `origin/dev2` (`711e323`). Дизайн, баннеры и страницы сохранены. Карточки товаров, поиск и чат теперь используют сервер. Это прототип, а не настоящий ekt.kz: источник по умолчанию — четыре синтетических товара; корзина EKT не подключена.

## Запуск всего приложения

Из корня репозитория:

```bash
cp .env.example .env
# Задайте свой локальный POSTGRES_PASSWORD в .env.
docker compose up --build
```

Витрина: <http://127.0.0.1:8080>. Swagger: <http://127.0.0.1:8000/docs>. Контейнер API применяет миграции и загружает индекс каталога. Nginx проксирует `/api` и `/health` к FastAPI. Порты привязаны к localhost; это локальное окружение разработки.

## Разработка без пересборки контейнеров

Нужны Python 3.12, Node 22.18+ (рекомендуется 24) и Docker для PostgreSQL. Из корня проекта:

```bash
cp .env.example .env  # Только если файла ещё нет.
# Установите одинаковый пароль в POSTGRES_PASSWORD и DATABASE_URL.
docker compose up -d db
uv venv .venv  # Только если окружения ещё нет.
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/alembic upgrade head
.venv/bin/python -m app.catalog_sync
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

В другом терминале:

```bash
cd web
npm ci
npm run dev
```

Откройте адрес Vite. `/api` автоматически проксируется на `127.0.0.1:8000`; настройки браузера и CORS не требуются. `uv sync` управляет отдельным CLI-консультантом и может удалить зависимости FastAPI из общего `.venv`: после него повторите установку `requirements.txt`.

По умолчанию `VITE_ASSISTANT_API_BASE=/api`. Для прямого подключения укажите полный префикс, например `http://127.0.0.1:8000/api`, и задайте `WIDGET_ORIGIN` на сервере равным точному origin витрины. Секреты никогда не помещайте в `VITE_*`.

Прежний автономный режим доступен явно через `VITE_ASSISTANT_API_BASE=demo` в `web/.env.local`. В нём старые карточки и локальная корзина остаются демонстрационными. При недоступности API серверный режим не переключается на них автоматически.

## Подключённые эндпоинты

| Интерфейс | API |
| --- | --- |
| Каталог без запроса | `GET /api/catalog/products?limit=100` |
| Поиск | `GET /api/catalog/search?q=...&limit=100` |
| Цена, остаток, характеристики карточек | `GET /api/catalog/products/{article}/fresh` |
| Создание сессии | `POST /api/chat/sessions` |
| История | `GET /api/chat/sessions/{id}/messages` |
| Сообщение | `POST /api/chat/sessions/{id}/messages`, JSON `{content, attachment_ids}` |
| Вложение | `POST /api/chat/sessions/{id}/attachments`, multipart `file` |
| Предложение из кнопки «Купить» | `POST /api/chat/sessions/{id}/offers`, JSON `{product_identifier, article, quantity}` |
| Подтверждение кнопкой | `POST /api/chat/sessions/{id}/offers/{offer_id}/confirm`, `Idempotency-Key` |

Сессия сохраняется в `sessionStorage` вкладки; история загружается с сервера. После пересоздания базы отсутствующая сессия заменяется новой. При обновлении страницы восстанавливается текст истории; карточки и незавершённые предложения заново не восстанавливаются, так как API истории их не возвращает.

Цена и остаток показываются только после успешного `/fresh`. Если сведения отсутствуют или источник недоступен, UI пишет «Цена не предоставлена»/«Наличие не подтверждено». Ноль и неизвестное значение различаются. Единица товара не выдумывается, если источник её не передал. Выборка ограничена 100 товарами; пагинация большого каталога пока не реализована.

Файлы: PDF, DOCX, XLSX, JPEG/PNG до 10 МБ. Старые DOC/XLS не поддерживаются бэкендом. Tesseract для OCR установлен в Docker-образе; при запуске Python напрямую его нужно установить отдельно.

Предложение создаётся отдельно от записи в корзину. Текст «да» не подтверждает серверное предложение. Только кнопка «Да, добавить» вызывает confirm; повтор запроса использует тот же ключ. При смене цены показывается новое предложение с новым подтверждением. Действующий backend использует недоступные EKT/cart adapters, поэтому сейчас запрос предложения честно завершается отказом и корзина не изменяется.

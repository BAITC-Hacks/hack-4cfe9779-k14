# Подбор аналогов и замен

`AnalogService` подбирает замену только после строгой проверки совместимости. Semantic/text similarity не является доказательством совместимости и применяется исключительно для ранжирования уже допущенных кандидатов. Пока правила не утверждены, runtime `UnavailableCompatibilityRules` fail-closed отклоняет всех кандидатов.

## Порядок обработки

1. `CatalogService.get_fresh_product` получает свежую карточку исходного товара.
2. Локальный индекс `CatalogService.search_candidates` формирует широкий набор кандидатов из той же категории.
3. Для каждого кандидата сервис получает свежую карточку и требует подтверждённую доступность.
4. `CompatibilityRules` отбрасывает позицию, если категория, обязательный параметр или профиль неизвестен; также отбрасывается любое различие обязательного параметра.
5. Только оставшиеся позиции получают deterministic score: количество совпавших обязательных полей и сходство названия. Ранжирование не может вернуть отклонённый кандидат.

Каждая рекомендация содержит структурированные `explanation.matches`, `explanation.differences` и `explanation.unknown`. Значение никогда не заменяется догадкой: неизвестный обязательный параметр означает отказ в совместимости.

## Конфигурация правил

`app/services/compatibility.py` задаёт интерфейс `CompatibilityRules`, а `ConfiguredCompatibilityRules` принимает профили по категориям из `app/config/compatibility_rules.py`. Этот файл намеренно пуст, пока нет утверждённых правил. Production implementation или утверждённый configuration source могут быть подставлены в `AnalogService` без изменения dialogue, catalog или ranking-кода.

До production запуска партнёр должен подтвердить: таксономию категорий, обязательные и запрещающие комбинации параметров для каждой категории, допустимые различия, признаки сертификации/регуляторных ограничений, правила замены бренда и доступный источник актуальных остатков. Пока такого контракта нет, отсутствующий профиль или любое отсутствующее критичное поле безопасно дают «нет подходящего аналога».

## Диалог

Запрос «найди аналог SKU» детерминированно маршрутизируется в `AnalogService`. Если текущая проверка наличия нашла нулевую доступность, `ChatService` также может приложить только прошедшие compatibility candidates. Если кандидатов нет, ответ прямо сообщает об этом; система не предлагает похожий по названию, но несовместимый товар.

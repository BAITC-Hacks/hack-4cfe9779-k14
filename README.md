# ИИ-ассистент для ekt.kz

Проект по кейсу HackAlem AI: чат на ekt.kz, который помогает посетителю найти электротехнические товары и оформить корзину.

[Запуск ИИ-консультанта на gpt-6-luna без бэкенда](docs/consultant.md). Ключ берётся из `OPENAI_API_KEY`; команда запуска — `uv run --frozen ekt-consultant` после `uv sync --locked`. Для поиска без ключа: `uv run --frozen ekt-consultant --search 05030003`. Пока используется явно обозначенный синтетический каталог, корзина не подключена.

[Пользовательский сценарий, архитектура и план MVP](docs/architecture.md).

[Этапы разработки и рекомендуемый технологический стек](docs/development-plan.md).

[Подробный план разработки ИИ-модуля и его интеграции с бэкендом](docs/model-development.md).

[Демовитрина, чат и контракт подключения Python-бэкенда](web/README.md).

Ассистент добавляет товар в корзину только после явного подтверждения клиента. Сервер проверяет количество и остаток непосредственно перед добавлением.
